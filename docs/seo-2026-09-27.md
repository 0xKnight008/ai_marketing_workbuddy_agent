## 本次已完成（本地，待部署）

- 首页中英西三语标题与摘要聚焦 AI 营销自动化、社交媒体工作流、内容生成、审批、发布、收件箱、CRM 线索和报告。
- 16 个公开 HTML 入口补齐 canonical、双向 hreflang（en / zh / es / x-default）、Open Graph 与 Twitter 元信息。
- 统一规范域名为 `https://www.piggybot.me`；英文 `/en/` 及其子页面的 canonical 指向对应根目录英文页面，中文与西语保持独立 canonical。语言导航的英文链接改用根路径。
- 三语首页加入 SoftwareApplication JSON-LD；没有添加未经核实的评分、评论或优惠报价。此标记描述产品实体，不保证富媒体搜索结果。
- 新增 robots.txt 与 sitemap.xml；地图包含 12 个规范公开地址，不重复列入 `/en/` 别名，也不列入控制台、付款或推荐链接。
- 标题和摘要统一维护于 `src/i18n/seo.json`，`npm run build` / `npm run build:ci` 自动重新生成 SEO 文件。单独运行 `vite build` 前需执行 `npm run seo:generate`。

## 下一阶段优先级

1. **提高正文可抓取性**：线上首页初始 HTML 的 root 为空，正文依赖 JavaScript。为营销页面做预渲染或 SSR，并确保动画不让无 JavaScript 的正文保持透明。Google 可渲染 JavaScript，但渲染仍是额外步骤。[Google JavaScript SEO 文档](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics)
2. **增加有实际内容的功能页**：建议创建 `/social-media-automation/`（内容改写、排期、审批）、`/ai-marketing-workflows/`（自然语言创建工作流、试运行、人工审核）、`/social-media-lead-generation/`（评论私信到 CRM）。每页放真实截图、操作步骤、适用场景及限制，通过首页导航和相关案例互链。当前这些地址仅为规划，尚未创建或加入地图。
3. **验证上线效果**：部署后核对 canonical 的最终地址是否返回 200、www/非 www 是否统一跳转、robots 与 sitemap 的内容类型是否正确。在 Search Console 提交 sitemap，检查三语页面渲染及 Google 选择的规范 URL，以 28 天窗口观察非品牌曝光、点击、CTR 和注册转化。构建目前提示主 JS 超过 500 kB，可在后续拆分控制台代码。

关键词布局是基于产品功能的建议，尚未使用关键词工具验证搜索量或竞争度。优先验证 `AI marketing automation`、`social media workflow automation`、`AI 营销自动化`，然后扩展到真实功能对应的长尾需求。

## 建议获取外链的 3 个渠道

这里的外链指其他网站链接回 Piggybot，不是在官网添加三个出站链接。下列是申请渠道，尚未提交，也未确认存在 Piggybot 专属页面。

| 优先级 | 渠道及官方入口 | 适合 Piggybot 的内容 | 执行要求 |
| --- | --- | --- | --- |
| 1 | [Product Hunt](https://www.producthunt.com/launch/preparing-for-launch) | 发布 AI 营销工作流产品，演示“内容生成 → 审批 → 发布 → 线索同步” | 准备可使用的产品、截图和演示视频，产品链接使用官网英文首页。官方允许创作者自行提交。仅邮件候补名单的产品不具备首页展示资格，见[官方说明](https://help.producthunt.com/en/articles/484932-can-i-submit-an-unreleased-product)。 |
| 2 | [AlternativeTo](https://alternativeto.net/faq/#add-a-new-application) | 建立产品条目，面向寻找社交媒体管理或营销自动化替代工具的用户 | 验证邮箱后选择 Suggest new application，准确填写功能、定价和平台；审核后公开。只将有实际功能重叠的工具列为替代对象，不宣称完全替代 Buffer、Hootsuite 或 Zapier。 |
| 3 | [Futurepedia](https://www.futurepedia.io/submit-tool) | 以 AI 工作流创建、内容运营及营销自动化切入 AI 工具目录 | 当前提交页包含付费方案，且需编辑审核。先评估目标受众与引流价值，核对结账价格，不为购买排名权重付费。 |

统一落地页建议：`https://www.piggybot.me/`。品牌锚文本使用 **Piggybot**，文案按平台受众调整，避免机械重复关键词。

可用英文简介：

> Piggybot helps creators and marketing teams build AI-powered workflows for content creation, approvals, social publishing, inbox management, CRM lead sync and reporting.

这些渠道可能带来相关访客、品牌发现和后续自然引用；实际链接可能带 nofollow、ugc 或 sponsored，不能承诺直接传递排名权重。Google 将为操纵排名而买卖链接列为链接垃圾行为，付费推广链接应正确标注。[Google 链接政策](https://developers.google.com/search/docs/essentials/spam-policies#link-spam)
